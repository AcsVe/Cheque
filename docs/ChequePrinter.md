# دليل برنامج طباعة الشيكات — ChequePrinter

| البند | القيمة |
|---|---|
| المستودع | `AcsVe/Cheque` |
| التحميل | `https://github.com/AcsVe/Cheque/releases/download/latest/ChequePrinterSetup.exe` |
| التقنية | Python 3.12 + PySide6 (Qt 6) + SQLite، يُبنى بـ PyInstaller ويُغلَّف بـ Inno Setup |
| البيانات | `%ProgramData%\ChequePrinter` (القاعدة `cheques.db`، `backups\`، `backgrounds\`، `license.json`) |
| المتطلبات | [`docs/Requirements.md`](Requirements.md) |

> **مبدأ الطباعة:** البرنامج يطبع **المعلومات فقط** (التاريخ، المستفيد، المبلغ رقماً وكتابةً، ختم التسطير) على **ورقة الشيك الأصلية** من دفتر الشيكات. صورة الشيك في الشاشة **محاكاة** للمعاينة فقط (رسمٌ لوجه شيك، أو صورة الشيك الفارغ للبنك إن حُمِّلت) ولا تُطبع أبداً.

## 1) التثبيت والتحديث
1. حمِّل `ChequePrinterSetup.exe` من الرابط أعلاه وشغّله (يطلب صلاحية المسؤول مرة واحدة).
2. للتحديث: حمِّل المثبّت الجديد وشغّله فوق القديم — البيانات والقوالب والترخيص تبقى كما هي.

## 2) أول تشغيل
1. **البنوك والحسابات ← + حساب بنكي جديد:** البنك (القالب)، اسم الحساب ورقمه، العملة، **رقم الشيك التالي**، وآخر رقم في دفتر الشيكات.
2. **معايرة القالب** (مرة واحدة لكل بنك):
   - «تحميل صورة الشيك الفارغ» (مسح ضوئي أو صورة مستقيمة لشيك فارغ من الدفتر، مقصوصة على حدود الشيك) — للمعاينة فقط ولا تُطبع. دونها يعرض البرنامج رسماً لوجه شيك أردني.
   - في «القالب والطابعة»: صيغة التاريخ، و«مئة/مائة»، والأرقام لاتينية أو عربية، وخانة الفلوس عند عدم وجودها (`---`) — كما في شيكات بنكك.
   - اسحب كل حقل إلى مكانه على الصورة، أو اكتب موضعه بالمليمتر. يظهر داخل كل إطار نصه التجريبي **كما يُطبع تماماً** (الرسم نفسه)، ولون الإطار يبيّن ملاءمته: أزرق = يتسع، برتقالي = صُغّر الخط تلقائياً ليتسع، أحمر = لا يتسع (كبّر الحقل).
   - حافة الإطار السفلى هي **سطر الشيك**: النص يجلس عليها («على السطر»)، أما خانات الدينار والفلس فالنص في وسطها («في وسط الإطار»).
   - أدوات المحاذاة فوق الشيك تعمل على الحقول المحددة (Ctrl+نقر أو السحب حولها): محاذاة الحواف اليسرى/اليمنى/العليا/السفلى، العرض نفسه، الارتفاع نفسه، توزيع أفقي/رأسي. الأسهم تحرّك المحدد 0.5 مم، ومع Shift ‏5 مم.
   - «طباعة صفحة المعايرة» على ورقة عادية، ثم ضع شيكاً فوقها مقابل الضوء.
   - صحّح «الإزاحة» في تبويب «القالب والطابعة» حتى تتطابق، ثم «طباعة شيك تجريبي» على شيك حقيقي ملغى.
   - اختر اتجاه إدخال الشيك: **أفقي** (الطرف الطويل أولاً) أو **عامودي**، وموضعه في درج الطابعة (وسط/يسار/يمين).
3. **إصدار شيك:** المستفيد، المبلغ، التسطير ← «حفظ وطباعة».

## 3) الاستخدام اليومي
- **إصدار شيك:** رقم الشيك يُقترح تلقائياً؛ زر البحث بجانب الرقم يفتح شيكاً محفوظاً، وبجانب المستفيد يختاره من القائمة. المبلغ يُكتب بالأرقام (اللاتينية أو العربية) ويُنسَّق تلقائياً بفاصل الآلاف (`1,250.750`) عند مغادرة الحقل.
- **سجل الشيكات:** تصفية لكل عمود وبحث وترتيب، والمجموع الظاهر، وتحديد عدة شيكات ← طباعة / إلغاء / حذف، وتصدير Excel.
- **الشيك التالف عند الطباعة:** ألغِه من السجل («إلغاء الشيك») وأصدر الشيك التالي؛ «إعادة طباعة» للرقم نفسه فقط عند الضرورة.
- **النسخ الاحتياطي:** تلقائي يومياً؛ يمكن تغيير المجلد إلى Google Drive أو OneDrive من الإعدادات، ومنها «استرجاع نسخة».

## 4) الترخيص
- البرنامج يعمل **14 يوماً تجريبياً**، ثم تتوقف الطباعة حتى إدخال المفتاح (البيانات تبقى).
- **العميل:** الترخيص ← ينسخ «بصمة هذا الجهاز» ويرسلها.
- **المورّد (أنت):** شغّل مولّد التراخيص نفسه المستخدم لجهاز الجرس (`bell_license_key_generator.py` بجانب `license_private_key.pem` — **خارج المستودع، لا يُرفعان أبداً**)، الصق البصمة، اختر المدة، وأرسل المفتاح الناتج.
- بصمة هذا البرنامج مختلفة عن بصمة مشغّل الجرس على الجهاز نفسه، فمفتاح أحدهما لا يفتح الآخر.
- عرض البصمة من سطر الأوامر: `ChequePrinter.exe --fingerprint` (في نافذة الترخيص أسهل).

## 5) للمطوّر
```
pip install -r requirements-dev.txt
python run.py                      # تشغيل من المصدر
QT_QPA_PLATFORM=offscreen python -m pytest -q tests
pyinstaller --noconfirm ChequePrinter.spec
iscc /DMyAppVersion=1.1.1 installer\ChequePrinter.iss
```

|---|---|
| `cheque_app/core/tafqeet.py` | المبلغ كتابةً (عربي فصيح بصيغ المعدود، وإنجليزي) |
| `cheque_app/core/db.py` | القاعدة والترحيلات المرقّمة وقواعد الحماية والنسخ |
| `cheque_app/core/templates.py` | القالب الافتراضي ومواضع الحقول بالمليمتر |
| `cheque_app/core/render.py` | رسم الشيك (طابعة/PDF/معاينة/صفحة معايرة/لوحة المعايرة) بكود واحد، وملاءمة كل نص لإطاره (`layout_cheque`) |
| `cheque_app/core/license.py` | البصمة والتحقق من التوقيع والفترة التجريبية |
| `cheque_app/ui/` | الواجهة: إصدار، سجل، مستفيدون، بنوك وحسابات، قالب ومعايرة، إعدادات |
| `cheque_app/ui/theme.py` | الألوان وورقة الأنماط (QSS) وارتفاع الحقول الموحّد (34px) والأيقونات (SVG داخلي) ومساعدات النماذج وأسماء الوصول |
| `installer/ChequePrinter.iss` | مثبّت Inno Setup |
| `.github/workflows/build.yml` | البناء والنشر الآلي |

- تغيير في القاعدة = إضافة عنصر جديد في نهاية `MIGRATIONS` (لا تعدّل القديم).

### ملاءمة النص للحقول (`render.layout_cheque`)
- كل حقل إطار بالمليمتر (`x, y, w, h`)؛ النص بحجم الخط المحدد، وإن لم يتسع عرضاً أو ارتفاعاً يُصغَّر بخطوات 0.25 نقطة حتى الحد الأدنى (`min(الحجم، max(6، 60% من الحجم))`)، ثم يُضغط أفقياً حتى 80%؛ وإن بقي أطول فحالته `overflow` وتظهر بالأحمر في المعايرة.
- المبلغ كتابةً: خط واحد للسطرين، ويُقسم عند حد الكلمة بقياس العرض الفعلي للسطر الأول على جهاز الطباعة نفسه.
- التاريخ والأرقام وخانات المبلغ ورقم الشيك تُرسم من اليسار إلى اليمين.
- القوالب المحفوظة بالإصدار 1.0.0 (بلا `layout`): غير المعايَرة تأخذ المواضع الجديدة، والمعايَرة تبقى مواضعها ونصها في وسط إطارها القديم فلا يتحرك المطبوع (`templates.upgrade_saved`).

### الواجهة وإمكانية الوصول
- كل عنصر تفاعلي له اسم وصول (`setAccessibleName`) بالعربية والإنجليزية، والأزرار ذات الأيقونة فقط لها تلميح؛ معاينة الشيك تصف محتواها (التاريخ، المستفيد، المبلغ…) لقارئ الشاشة. الاختبار `test_every_control_has_an_accessible_name` يمرّ على كل النوافذ ويفشل عند أي نقص.
- ملف PDF المطبوع يحمل عنواناً وصفياً («شيك 100 — المستفيد») ومُنشئه ChequePrinter؛ الشيك المطبوع لا صور فيه.
- المقاسات تتبع الخط الفعلي على الجهاز (حجم النص في ويندوز وتكبير الشاشة 125% و150%): ارتفاع الحقول والأزرار `theme.control_height()` (لا يقل عن 34px)، والحقول ذات المقاس `ltr(w, عرض)`/`fit(w, عرض)` تتسع لأعرض رقم أو تاريخ أو خيار، فلا يُقص نص.
- كل قسم من النافذة الرئيسية وكل نموذج داخل منطقة تمرير (`theme.scroll_page`)، فتصل عجلة الفأرة إلى آخر النافذة على الشاشات الصغيرة، وتُفتح النوافذ بمقاس الشاشة المتاح (`theme.fit_to_screen`). صفوف الأزرار تنتقل إلى سطر جديد بدل أن تُقص (`theme.flow_row`). عجلة الفأرة فوق حقل رقم أو قائمة غير محددة تمرّر الصفحة ولا تغيّر القيمة. الاختبار `test_nothing_clipped_on_small_screens_and_large_text` يحرس ذلك بخط 15 نقطة.
- نافذة جديدة: استخدم `theme.field()` للحقول (عنوان مرتبط واسم وصول)، و`theme.button()`/`icon_button()` للأزرار، و`card()` للمجموعات.
- رفع الإصدار: `cheque_app/__init__.py` ← `__version__`.
