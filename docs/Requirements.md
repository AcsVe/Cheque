# متطلبات برنامج طباعة الشيكات — ChequePrinter

> وثيقة المتطلبات المعتمدة للإصدار 1.0 (2026-10-23). المرجع: فيديو البرنامج المطلوب محاكاته (نافذة «ChequeForm») وطلبات المستخدم.

## 1) الهدف
برنامج ويندوز مستقل (`ChequePrinter.exe` بمثبّت Inno Setup) يُصدر الشيكات البنكية ويطبعها مباشرة على الشيك الفعلي في الطابعة، ويحفظ سجلاً كاملاً بها، ويعمل **محلياً** على الجهاز دون إنترنت، بترخيص استخدام لكل جهاز.

## 2) نطاق التشغيل
| البند | المتطلب |
|---|---|
| النظام | Windows 10/11 ‏64-بت |
| الشبكة | لا يحتاج إنترنت ولا خادماً؛ كل البيانات على الجهاز (الطابعة قد تكون محلية أو شبكية) |
| البيانات | قاعدة SQLite في `%ProgramData%\ChequePrinter` مشتركة بين مستخدمي الجهاز |
| اللغة | واجهة عربية رسمية (من اليمين لليسار)، مع الإنجليزية من الإعدادات |
| العملة | الدينار الأردني (3 خانات للفلوس) افتراضياً، والدولار واليورو متاحان لكل حساب |

## 3) المتطلبات الوظيفية

### 3.1 إصدار شيك (مطابق للنموذج في الفيديو)
- FR-1 الحساب البنكي (يحدد البنك وقالب الطباعة والعملة).
- FR-2 رقم الشيك: يُقترح تلقائياً الرقم التالي في دفتر الحساب، وزر «؟» يفتح الشيكات المحفوظة للاختيار والتعديل، وتنبيه عند كتابة رقم مستخدم.
- FR-3 التاريخ بالتقويم المنسدل.
- FR-4 اسم المستفيد: كتابة مع إكمال تلقائي من قائمة المستفيدين، وزر «؟» لاختياره من القائمة؛ يُحفظ المستفيد الجديد تلقائياً.
- FR-5 المبلغ رقماً (يقبل الأرقام العربية والفاصلة)، والمبلغ **كتابةً يُولَّد تلقائياً** بالعربية الفصحى بصيغ المعدود الصحيحة (دينار واحد، ديناران، ثلاثة دنانير، أحد عشر دينارًا، مئتا دينار، ألفا دينار…) أو بالإنجليزية حسب القالب، مع خيار التعديل اليدوي.
- FR-6 التسطير: بدون تسطير / المستفيد الأول / بالحساب / المستفيد الأول + بالحساب، ويُطبع ختم التسطير (خطان متوازيان والنص بينهما، بزاوية قابلة للضبط). نصوص الختم قابلة للتعديل.
- FR-7 البيان (سبب الدفع) — يُحفظ، ويُطبع فقط إن فُعِّل في القالب.
- FR-8 الأزرار: حفظ البيانات، حفظ وطباعة، إعادة طباعة، معاينة الطباعة، شيك جديد.
- FR-9 معاينة حية للشيك كما سيُطبع، فوق صورة الشيك الفارغ للبنك إن حُمِّلت.

### 3.2 قوالب البنوك والمعايرة
- FR-10 قالب لكل بنك: مقاس الشيك بالمليمتر، الخط، لغة المبلغ كتابةً، الفلوس كلمات أو أرقام، صيغة التاريخ، إطار رقم الدنانير (`#1250#`)، فاصل الآلاف.
- FR-11 حقول قابلة للتحريك بالسحب على صورة الشيك أو بكتابة الموضع: التاريخ، المستفيد، المبلغ كتابةً (سطران مع تقسيم تلقائي عند حد الكلمة)، الدنانير، الفلوس، المبلغ كاملاً، ختم التسطير، البيان، رقم الشيك؛ لكل حقل: يُطبع/لا يُطبع، الموضع، المقاس، حجم الخط، المحاذاة، عريض، مسافة الأرقام (للتاريخ في مربعات).
- FR-12 إعدادات التغذية في الطابعة: الورق (بمقاس الشيك / A4 / Letter)، الاتجاه (أفقي / عامودي / عامودي معكوس)، الموضع (وسط / يسار / يمين)، إزاحة أفقية ورأسية بالمليمتر، وإزاحة كل الحقول دفعة واحدة.
- FR-13 طباعة «صفحة المعايرة» (شبكة مليمترية وإطارات الحقول بأسمائها) و«شيك تجريبي».
- FR-14 نسخ قالب، واستعادة القالب الافتراضي.

### 3.3 القوائم (لكل قائمة: إضافة، تعديل، تحديد متعدد مع إجراءات جماعية، رؤوس ثابتة، تصفية لكل عمود، ترتيب، بحث عام، تصدير Excel)
- FR-15 سجل الشيكات: فترة من/إلى، المجموع الظاهر، فتح للتعديل، طباعة المحدد (بالترتيب)، إلغاء الشيك، حذف.
- FR-16 المستفيدون: إضافة، تعديل، تفعيل/إيقاف، حذف، إضافة قائمة (لصق أو Excel/CSV).
- FR-17 البنوك والحسابات: الحساب (البنك، الاسم، الرقم، العملة، رقم الشيك التالي، آخر رقم في الدفتر)، الحساب الافتراضي، تفعيل/إيقاف، حذف.

### 3.4 حماية البيانات
- FR-18 لا يتكرر رقم شيك في الحساب نفسه، ولا يتجاوز آخر رقم في الدفتر.
- FR-19 الشيك المطبوع لا يُحذف (يُلغى ويبقى رقمه مسجلاً)، والشيك الملغى لا يُعدّل، وتعديل شيك مطبوع يحتاج تأكيداً.
- FR-20 لا يُحذف بنك له حسابات، ولا حساب له شيكات، ولا مستفيد له شيكات (يُعرض الإيقاف بديلاً).
- FR-21 سجل تدقيق داخلي لكل حفظ وطباعة وإلغاء وحذف.
- FR-22 نسخة احتياطية تلقائية يومياً عند فتح البرنامج (تُحفظ آخر 30)، ونسخة يدوية، واسترجاع (مع نسخة أمان من الحالي أولاً).

### 3.5 الترخيص
- FR-23 بصمة جهاز من 16 خانة (اللوحة الأم ← معرّف ويندوز ← بطاقة الشبكة).
- FR-24 مفتاح بصيغة `YYYYMMDD:التوقيع` أو `PERMANENT:التوقيع`، توقيع ECDSA P-256 على «البصمة|الانتهاء»، يُصدره المورّد بالمولّد الخاص (المفتاح الخاص خارج البرنامج).
- FR-25 فترة تجريبية 14 يوماً كاملة الميزات، ثم تتوقف **الطباعة فقط**، وتبقى البيانات قابلة للعرض والتصدير.
- FR-26 حالة الترخيص ظاهرة في عنوان النافذة، ونافذة الترخيص تعرض البصمة مع زر نسخ وحقل المفتاح.

## 4) التثبيت والتحديث
- NFR-1 مثبّت واحد `ChequePrinterSetup.exe` (Inno Setup): Program Files، اختصار سطح المكتب وقائمة ابدأ، إنشاء مجلد البيانات بصلاحية كتابة للمستخدمين.
- NFR-2 التحديث = تشغيل المثبّت الجديد فوق القديم؛ البيانات والقوالب والترخيص لا تُمس، ولا عند إلغاء التثبيت.
- NFR-3 البناء آلي في GitHub Actions مع كل تعديل: اختبارات ← PyInstaller ← اختبار ذاتي للبرنامج المبني ← Inno Setup ← رابط تحميل ثابت.

## 5) معايير القبول
- الاختبارات الآلية تنجح (التفقيط، القاعدة، الترخيص، الرسم، الواجهة).
- شيك مطبوع على الشيك الحقيقي بعد معايرة واحدة تقع حقوله في أماكنها بفارق لا يتجاوز 1 مم.
- المبلغ كتابةً صحيح لغوياً لكل المبالغ من 0.001 إلى 999,999,999.999.
