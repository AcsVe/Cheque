# ChequePrinter — برنامج طباعة الشيكات

برنامج ويندوز لإصدار الشيكات وطباعتها على شيكات البنوك الفعلية: المبلغ كتابةً بالعربية الفصحى تلقائياً، ختم التسطير،
قالب قابل للمعايرة لكل بنك بالسحب والإفلات، سجل كامل بالشيكات، يعمل محلياً دون إنترنت، بترخيص لكل جهاز.
